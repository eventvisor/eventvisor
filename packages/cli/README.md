# @eventvisor/cli

The Eventvisor command line interface.

```bash
npx eventvisor lint
npx eventvisor test
npx eventvisor build
npx eventvisor catalog
```

Use `--tag`, `--target`, or `--set` where supported to work with a selected datafile boundary. Other commands include `list`, `info`, `find-usage`, `simulate`, `benchmark`, and `generate-code`.

Visit [https://eventvisor.org/docs/cli](https://eventvisor.org/docs/cli) for more information.
